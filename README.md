# Web UI Showcase Collection

A collection of static web interface user interfaces hosted via **GitHub Pages**. This repository contains front-end design prototypes for cultural, news, and digital library web applications.

---

## 🌐 Live Demos & Sub-Projects

### 1. Komeh Shah Magazine Store (`/magazine-ui-main/`)
An interactive digital showcase UI for browsing cultural and religious magazine editions.

* 🔗 **Live Demo:** [Magazine Store Web UI](https://danialkh.github.io/test-action-html/magazine-ui-main/)
* **Key Features:**
  * Interactive bookshelf-style visual display for archived magazine issues.
  * Filter/dropdown navigation by publication year (e.g., 1395).
  * Persian / RTL site layout featuring home, about, contact, and archives navigation.

---

### 2. Sabeqoon Holy Sites & News Platform (`/first_page_sabeqoon-main/`)
A news portal and image gallery platform tailored for cultural heritage and holy site news updates.

* 🔗 **Live Demo:** [Sabeqoon Platform UI](https://danialkh.github.io/test-action-html/first_page_sabeqoon-main/)
* **Key Features:**
  * Multi-source news feed layout categorized by region and organization.
  * Embedded photo and video gallery grid with pagination controls.
  * Regional dropdown filters (e.g., Sistan and Baluchestan province updates).
